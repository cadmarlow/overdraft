# Modèles de voitures

Tous sous licence Creative Commons Attribution 4.0 : https://creativecommons.org/licenses/by/4.0/

Modifications apportées pour le jeu : mise à l'échelle, orientation, séparation carrosserie, vitres et roues, regroupement
des textures sur un atlas avec masque de peinture, simplification, renommage. Les logos Khronos du modèle Car Concept ont été
retirés. Aucune de ces œuvres n'est approuvée par son auteur pour cet usage.
