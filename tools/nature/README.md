# Herbe

Les textures d'herbe de `assets/nature` sortent d'ici. Rien de ce dossier n'est chargé par le jeu. Les arbres ont
leur propre chaîne : `tools/trees`.

Sources, en CC0 : [ambientCG](https://ambientcg.com) (Grass001, Grass005, en 2K-JPG, chacun dans un dossier à son nom).

```bash
cd tools/nature
npm install
node build-textures.mjs <dossier des téléchargements>
```
